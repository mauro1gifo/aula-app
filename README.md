# Aula.

Chat en grupo pensado para clases. Canales, horario compartido, anclas (`/deberes mates`) y avatar Funko.

## Abrir en local

Abre `index.html` en el navegador (mejor vista móvil).

## Desplegar en Vercel

```bash
npx vercel --prod
```

O conecta este repo a Vercel en el dashboard.

## Versión cloud (multi-dispositivo)

Ver carpeta [`cloud/`](cloud/): esquema SQL de Supabase + instrucciones.

## Qué incluye (versión localStorage)

- Bienvenida, registro con diseñador de Funko, login
- Dock de cristal: Chats · Buscar · Crear · Ajustes
- Grupos con canales (general, mates, lengua, historia, inglés)
- Burbujas estilo iMessage, stickers, fotos
- Anclas indexables
- Mini horario L–V
- DMs, bloqueo de contactos
- Datos solo en este dispositivo (localStorage)

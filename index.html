Repositorio listo con esquema Supabase y config de Vercel.

Para la app completa (un solo index.html de ~62 KB):

  1. En GitHub: Add file → Upload files
  2. Sube el index.html de la app y reemplaza este
  3. O clona el repo y haz git push con ese archivo

Luego: npx vercel --prod o conecta el repo en Vercel.
